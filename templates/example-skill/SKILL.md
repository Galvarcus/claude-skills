# Example Skill

## Purpose

This is a starter skill demonstrating the required structure. Replace it or remove this directory after adding your own skills.

## Workflow

1. Identify the user's requested outcome and relevant constraints.
2. Inspect the available inputs before making assumptions.
3. Carry out the task using explicit, verifiable steps.
4. Check the result against the requested outcome.
5. Report the result and any limitations.

## Rules

- Prefer specific, actionable instructions.
- Do not claim to have run checks that were not run.
- Keep supporting reference material in separate files when it is only needed for some tasks.

## Output

Provide the requested result and a concise account of relevant decisions or checks.
