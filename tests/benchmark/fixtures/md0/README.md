# Quillmark

Quillmark is a really powerful and super easy-to-use tool that can be used in order to basically convert your Markdown notes into nicely formatted PDF documents. It is our belief that it is the very best tool of its kind that is currently available.

## Getting Started

In order to get started with Quillmark, the first thing that you will need to do is to install it. Installation can be performed by means of pip, which is the Python package manager:

```
pip install quillmark
```

It should be noted that Python 3.10 or a later version of Python is required in order for Quillmark to be able to run properly.

## Usage

Once Quillmark has been installed, it can be run from the command line. You simply just need to pass the name of the file that you want to convert:

```
quillmark notes.md -o notes.pdf
```

For more information, [click here](https://example.com/quillmark/docs).

## Other Things

There are a number of options that are able to be configured. The theme can be changed by the user with the `--theme` flag. The page size can also be changed with the `--page` flag, if that is something that you would like to do.
